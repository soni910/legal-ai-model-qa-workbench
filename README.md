# Legal AI Model QA Workbench

**Full title:** Legal AI Model QA Workbench: Contract Intelligence Dataset, Evaluation Harness, Error Taxonomy, and Annotation Guide.

## Overview
This is a free portfolio project that simulates how a legal AI product specialist, contract-intelligence analyst, or model QA reviewer can evaluate AI extraction quality for legal and business terms from contracts.

## Current Status
This repository currently contains the **initial skeleton**:
- Streamlit app shell and multipage structure
- utility module placeholders
- predeploy check script scaffold
- folders for data, documentation, tests, and scripts

## Important Constraints
- Synthetic contract data only
- No client data
- No legal advice
- No paid APIs or external LLM APIs
- No database
- No authentication
- No secrets or API keys
- Streamlit Community Cloud deployable

## Local Run
```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
